# Repository contribution language

Use English for all new or modified code, identifiers, comments, docstrings,
command-line messages, documentation, commit messages, and pull request text.
User-facing chat can follow the user's language.

Do not introduce Russian-language content into Git contributions. Existing
upstream reference materials may contain Russian; preserve them rather than
translating or rewriting baseline artifacts without a specific request.

Keep credentials in ignored local configuration. Commit and push only when
authorized by the user; creating a local document does not authorize publishing.
