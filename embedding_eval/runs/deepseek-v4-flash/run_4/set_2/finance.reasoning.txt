We need to estimate the PE ratio for a firm given the characteristics. The PE ratio is the price-to-earnings ratio. Typically, we can estimate the intrinsic PE using the dividend discount model (or free cash flow to equity) but since we have payout ratios, we can think of the PE as a function of growth and payout. Generally, the PE ratio is derived from the Gordon Growth Model for a stable growth firm: P/E = (Payout ratio) / (required return - growth). For a two-stage growth model, we need to compute the present value of expected dividends (or earnings) and then divide by current earnings.

Given the information: high growth period length = 5 years, growth rate in first 5 years = 25%, payout ratio = 20%. After 5 years, growth = 8%, payout ratio = 50%. Beta=1.0, risk-free rate=6%, equity risk premium=5.5%, so cost of equity = 6%+1*5.5% = 11.5%. So required return, r = 11.5%.

We want the PE ratio: price per share / earnings per share. We can assume earnings per share today (E0) = 1 for convenience; then we can compute the price as the present value of expected future dividends per share. Since dividends are paid out from earnings, we can compute dividends in each year.
