We are given a 7x7 integer matrix A with only eigenvalue -3. So the characteristic polynomial is (λ+3)^7 = 0, so the only eigenvalue is -3 with algebraic multiplicity 7. But the minimal polynomial is (λ+3)^k for some k between 1 and 7, depending on the size of the largest Jordan block. We need to find the minimal polynomial of A.

We are to find the monic polynomial m(x) such that m(A)=0, with least degree. Since the eigenvalue is -3, m(x) = (x+3)^k for some k. So we need to find the smallest k such that (A+3I)^k = 0. That is, the index of nilpotency of the nilpotent matrix N = A+3I. So we need to compute powers of N until we get zero. The minimal polynomial has degree k, and coefficients are for (x+3)^k = x^k + ... + 3^k. Since it's monic, we list coefficients from highest degree down to constant term.

Thus we need to compute N = A+3I, then compute N^2, N^3, ... until we find the smallest k such that N^k = 0. Since A is 7x7, k ≤ 7. We can compute powers.
