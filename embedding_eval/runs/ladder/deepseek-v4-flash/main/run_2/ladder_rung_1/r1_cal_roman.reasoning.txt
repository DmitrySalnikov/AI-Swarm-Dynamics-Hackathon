Thus conversion:

- If the expression is "Kalendis <month>" -> date is 01.(month number)
- If "Nonis <month>" -> date is (Nones day).(month number)
- If "Idibus <month>" -> date is (Ides day).(month number)

- If "pridie Idus <month>" -> day = (Ides day) - 1, same month.
- If "pridie Kalendas <month>" -> day = last day of previous month (month before the named month). So we need to know the previous month's length.
- If "ante diem N Nonas <month>" -> day = (Nones day) - (N-1), same month.
- If "ante diem N Idus <month>" -> day = (Ides day) - (N-1), same month.
- If "ante diem N Kalendas <month>" -> day = (length of previous month) + 2 - N, and month = previous month.
