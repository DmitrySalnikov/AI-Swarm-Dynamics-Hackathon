We can use work-energy theorem, considering work done by gravity and friction. For each segment, the change in kinetic energy equals work done by gravity and friction. Since the block stays in contact and no air resistance, the net work equals change in kinetic energy.

We can treat each segment sequentially. For each segment i, given initial speed v_i, we compute final speed v_{i+1} using:

So it's easier: W_gravity = m g * (vertical drop) = m g * (initial height - final height). So for a downhill incline of length L and angle θ (angle to horizontal), the vertical drop = L sin θ. For horizontal segment, W_gravity = 0.

Work by friction: Kinetic friction force magnitude = μ m g cos θ for inclines (since normal force = m g cos θ on incline), and for horizontal, normal = m g, so friction = μ m g. Friction always opposes motion, so work done by friction is negative: W_friction = - μ m g cos θ * L (for incline) or - μ m g L (for horizontal). Note: on downhill incline, the block moves downward, friction opposes motion (up the incline), so work is negative; on uphill, block moves upward, friction also opposes motion (down the incline), so also negative. So friction always does negative work.
