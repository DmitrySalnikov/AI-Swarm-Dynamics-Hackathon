For reflector cases: "a stationary source emitting frequency f sends sound to a large flat reflector that moves at speed v_r (away or toward the source); frequency of the reflected sound received back at the source." That is a two-step Doppler effect: first, the sound from stationary source hits the moving reflector (which acts as an observer), then the reflector re-emits the sound as a moving source back to the stationary source (which is now the observer). So we need to compute the frequency observed by the reflector (first Doppler) and then the frequency observed by the original source from the moving reflector (second Doppler). Since the reflector is moving, we need to carefully consider direction.

General Doppler formula: For sound waves, the observed frequency f' = f * (v ± v_o) / (v ∓ v_s) where v is speed of sound, v_o is speed of observer relative to medium, v_s is speed of source relative to medium. The signs: if observer moves toward source, numerator uses plus; if away, minus. If source moves toward observer, denominator uses minus; if away, plus. Alternatively, we can use the formula: f' = f * (v + v_o) / (v - v_s) when both are moving toward each other (taking positive direction from source to observer). But careful: need consistent sign convention.
