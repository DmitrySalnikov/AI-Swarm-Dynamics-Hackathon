We need to compute the speed after each segment, considering work-energy: change in kinetic energy = work done by gravity + work done by friction. Since the track is straight segments, we can treat each segment individually, using the initial speed at the beginning of the segment, compute final speed via energy.

We need to account for sign: For downhill incline, gravity aids motion; for uphill, gravity opposes motion. Friction always opposes motion, so work done by friction is negative. The work done by gravity over a segment: if the block moves a distance L along the incline, the vertical height change is ± L sinθ, where positive indicates decrease in height (downhill) gives positive work by gravity (mg * height drop). For uphill, height gain, gravity does negative work.

So for each segment, we have: ½ m v_f² - ½ m v_i² = m g Δh - μ m g cosθ * L, where Δh = L sinθ for downhill (positive, so +), for uphill Δh = - L sinθ (negative). Actually careful: work done by gravity = -ΔU = - (m g Δy) where Δy is change in vertical position (final - initial). If we set y increasing upward, then for downhill, Δy = - L sinθ, so work = - mg Δy = - mg (-L sinθ) = mg L sinθ. For uphill, Δy = + L sinθ, work = -mg L sinθ. So indeed work by gravity = mg L sinθ for downhill, and -mg L sinθ for uphill. So we can write: W_grav = ± mg L sinθ, where plus for downhill, minus for uphill.

Work by friction: always - μ m g cosθ * L (since friction force = μ N = μ mg cosθ, opposite to motion, so negative work). So:

ΔKE = (1/2) m (v_f^2 - v_i^2) = ± mg L sinθ - μ mg L cosθ

Cancel m:

(1/2)(v_f^2 - v_i^2) = ± g L sinθ - μ g L cosθ

=> v_f^2 = v_i^2 + 2gL( ± sinθ - μ cosθ )

So we can compute v_f from v_i.
