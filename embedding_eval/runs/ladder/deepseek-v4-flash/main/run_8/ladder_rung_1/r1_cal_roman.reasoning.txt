We are given 160 Roman calendar dates to convert to modern day-month (DD.MM). We need to compute each date based on rules: each month has Kalends (1st), Nones, Ides. For March, May, July, October, Nones on 7th, Ides on 15th; for other months, Nones on 5th, Ides on 13th. The year is common (non-leap) so February has 28 days. We have to convert each phrase to a day and month.

First, recall the formula: "ante diem N Kalendas/Nonas/Idus month" means counting backwards inclusively from that named day. So if named day is D (e.g., Kalends = 1, Nones = Nones date, Ides = Ides date), then the date is D - (N - 1). So "ante diem N" means N days before the named day inclusive, so the actual day is (named day) - (N-1). "pridie" = ante diem II, so day before.

Also, "Kalendis/Nonis/Idibus month" (ablative) is the named day itself.

Important: Days after Ides are counted towards Kalends of next month. So when we see "ante diem N Kalendas month", the month in accusative is the month of the Kalends (the 1st of that month), and the date falls in the previous month. So we need to determine the month of the date.

Similarly, for "ante diem N Nonas month" or "ante diem N Idus month", the named day is in that month, so the date is also in that month (unless it goes before the 1st? Actually, Nones and Ides are within the month, so counting backwards stays within the same month, unless N is large enough to go before the 1st? But typically N for Nones and Ides is small, so it stays within month. For Kalends, it's referring to next month, so date is in previous month.

We must also consider that months have different lengths, and the named days are given.
