We need to convert 160 Roman calendar dates to modern day-month format (DD.MM). We have a non-leap year, so February has 28 days. The rules: each month has Kalends (1st), Nones, and Ides. The Nones and Ides dates vary: for months with 31 days (March, May, July, October) Nones on 7th, Ides on 15th; for other months (January, February, April, June, August, September, November, December) Nones on 5th, Ides on 13th. But note: January has 31 days but Nones on 5th? Actually according to table: January 31 days, Nones on 5th, Ides on 13th. So the pattern: March, May, July, October have Nones on 7th, Ides on 15th; all others have Nones on 5th, Ides on 13th. So we need to compute each date.

Interpretation:
- "Kalendis/Nonis/Idibus <month>" = that named day itself. So Kalendis Februariis = Feb 1.
- "ante diem N Kalendas/Nonas/Idus <month>" means count backwards inclusively from that named day. So ante diem IV Nonas Septembres = 4 days before Nones of September inclusive? Actually "ante diem N" means N days before, counting the named day as day 1. So the date is the named day minus (N-1) days. For example, ante diem II (pridie) is the day before. So if Nones is on 5th, then ante diem IV Nonas = 4 days before Nones inclusive? Let's compute: Named day = Nones = 5th. Count backwards: day1 = 5th, day2 = 4th, day3 = 3rd, day4 = 2nd. So ante diem IV Nonas = 2nd. So formula: date = named day - (N-1). So we need to know the named day's date in the month.
- For days after Ides, they are counted towards Kalends of next month. So "ante diem N Kalendas <next month>" means counting backwards from the Kalends of that next month, so the date falls in the previous month. For example, ante diem XIV Kalendas Octobres means 14 days before Kalends of October, inclusive. Kalends of October is Oct 1. So counting backwards: day1 = Oct 1, day2 = Sep 30, day3 = Sep 29, ..., day14 = Sep 18. So date is September 18. So careful: the month in the phrase is the month of the Kalends, so the actual date is in the previous month.

Thus we need to compute each of the 160 dates.
