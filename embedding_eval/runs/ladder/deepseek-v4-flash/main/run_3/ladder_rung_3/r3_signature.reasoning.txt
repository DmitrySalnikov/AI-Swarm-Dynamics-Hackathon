We are given a 7x7 symmetric integer matrix A. Need to find signature (p, q) of the quadratic form Q(x)=x^T A x. The signature is the number of positive and negative eigenvalues (counted with multiplicities) after diagonalization over reals, equivalently the number of positive and negative coefficients in a diagonal form via Lagrange's method (Sylvester's law of inertia). Since the matrix is symmetric, we can compute its eigenvalues or perform Gaussian elimination while keeping track of signs. But computing eigenvalues of a 7x7 integer matrix by hand is messy. We can instead perform a congruence transformation (i.e., apply simultaneous row and column operations to reduce to diagonal form, while preserving the signature). This is essentially completing squares or using LDL^T decomposition with pivoting.

One approach: Perform symmetric Gaussian elimination (i.e., for a symmetric matrix, we can do row operations and corresponding column operations to eliminate off-diagonal entries, resulting in a block diagonal or diagonal matrix). However, note that we need to handle potential zero pivots; we may need to use pivoting or treat them appropriately.
