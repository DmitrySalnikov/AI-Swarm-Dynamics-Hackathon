We are given a 7x7 integer matrix A with eigenvalue 1 only. So the characteristic polynomial is (λ-1)^7, and the minimal polynomial is (λ-1)^k for some k between 1 and 7. We need to determine the Jordan normal form, i.e., the sizes of the Jordan blocks for eigenvalue 1. The Jordan blocks are determined by the nullities of (A-I)^j for j=1,2,... up to the size where the nullity stabilizes.

Let N_j = nullity of (A-I)^j. Then the number of Jordan blocks of size at least j is N_j - N_{j-1}. And the number of blocks of size exactly j is (N_j - N_{j-1}) - (N_{j+1} - N_j). Also, we know that N_0 = 0 (by convention). We'll compute ranks or nullities of powers.

Define B = A - I. Then B is a 7x7 matrix. Compute its rank, then nullity = 7 - rank(B). Similarly for B^2, B^3, etc., until nullity stabilizes at 7 (since only eigenvalue 0 for B). The Jordan block sizes correspond to the sizes of the nilpotent part.
