We'll compute the speed after each segment using work-energy principle: the change in kinetic energy equals work done by friction and gravity. For each segment, we need to consider the component of gravity along the incline (if inclined) and friction force.

Let’s denote:

For a segment of length L, incline angle θ relative to horizontal. "Downhill" means the block moves down the incline: the gravitational component helps motion, i.e., it adds energy. "Uphill" means it moves up: gravity opposes motion, removing energy. Friction always opposes motion, so work done by friction is negative.

The net work done on the block equals change in kinetic energy: ΔK = K_final - K_initial = W_gravity + W_friction.

For a segment with incline angle θ (where θ = 0 for horizontal), the gravitational work: W_gravity = m * g * (vertical displacement). For downhill: vertical displacement = -L sin θ? Actually if we define positive direction as upward, then when moving downhill, the block descends, so vertical displacement is negative; but work done by gravity is positive if the block moves downward. Typically, work done by gravity = - m g Δy, where Δy is change in height (final - initial). If the block moves downhill, Δy is negative, so - m g Δy = - m g (negative) = positive. So easier: W_gravity = m g * (drop in height) = m g * (L sin θ) for downhill (since drop = L sin θ). For uphill, the block gains height, so work by gravity is negative: W_gravity = - m g * (L sin θ). So we can write:

W_gravity = ± m g L sin θ, where sign is + for downhill (motion down) and - for uphill (motion up). For horizontal, sin θ=0 so zero.

Friction work: W_friction = - f_k * L = - μ m g cos θ * L, because kinetic friction force magnitude = μ N = μ m g cos θ (since normal force = m g cos θ on incline; on horizontal, cos0=1 so μ m g). The negative sign because friction opposes displacement.

Thus, net work: ΔK = ± m g L sin θ - μ m g cos θ L.

So the change in kinetic energy per unit mass: Δ(v^2/2) = ± g L sin θ - μ g L cos θ.

Thus, v_final^2 = v_initial^2 + 2 * ( ± g L sin θ - μ g L cos θ ).

Alternatively: v_final^2 = v_initial^2 + 2 g L ( ± sin θ - μ cos θ ).

Note: For horizontal, sin0=0, cos0=1, so formula reduces to v_f^2 = v_i^2 - 2 μ g L.
