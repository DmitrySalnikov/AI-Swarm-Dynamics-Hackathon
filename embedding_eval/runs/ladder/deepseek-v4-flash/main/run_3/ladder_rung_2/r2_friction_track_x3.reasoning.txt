Actually "downhill incline" means the block moves downward along the incline; "uphill incline" means it moves upward. So the component of gravity along the incline will either accelerate (downhill) or decelerate (uphill). Friction always opposes motion, so it does negative work.

For a segment of length L, with angle θ relative to horizontal (given as angle to horizontal; for downhill, the incline goes downward; for uphill, upward). The force of gravity component along the incline: mg sinθ for downhill (positive direction of motion), and -mg sinθ for uphill (since opposite to motion). Friction force: μ mg cosθ (since normal force = mg cosθ on incline; on horizontal, θ=0, so normal = mg, friction = μ mg). Friction always opposes motion, so work done by friction = -μ mg cosθ * L (for any incline, cosθ positive; for horizontal cos0=1). Work done by gravity: for downhill, +mg sinθ * L; for uphill, -mg sinθ * L.

Thus net work done on block: W = (mg sinθ * L) * (sign: +1 for downhill, -1 for uphill) - μ mg cosθ L.

Change in kinetic energy: ΔK = (1/2)m(v_f^2 - v_i^2) = W.

Thus v_f^2 = v_i^2 + 2g [ (sign) sinθ L - μ cosθ L ].

Note: sign is +1 for downhill, -1 for uphill.

So we can compute v_f^2 after each segment, using v_f^2 = v_i^2 + 2g L ( sinθ * sign - μ cosθ ). Since mass cancels.

For horizontal segments: θ=0, sinθ=0, cosθ=1, so term = -μ L, so v_f^2 = v_i^2 - 2g μ L.
