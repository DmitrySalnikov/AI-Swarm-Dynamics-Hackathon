We need to convert each Roman date to modern day-month format (DD.MM). All dates are in a common (non-leap) year. We have the rules: Kalends=1st, Nones and Ides as per month table. "ante diem N Kalendas/Nonas/Idus" counts backwards inclusive, so the named day is day 1. So the actual day = (named day) - (N-1). For "pridie" it's day before, so N=2 effectively. For "Kalendis/Nonis/Idibus" it's the named day itself.

Important: When counting towards Kalends of next month, the date falls in the previous month. So for "ante diem N Kalendas <next month>" we are in the current month, counting backwards from the 1st of next month. For example, "ante diem XIV Kalendas Octobres" means 14 days before the Kalends of October (which is Oct 1), counting inclusively, so it is Sept 18? Let's check: If Kalends= Oct 1, then ante diem XIV means day 14 before that inclusive: Oct 1 is day1, Sep 30 is day2, Sep 29 day3, ... So day = Oct 1 - (14-1) = Oct 1 -13 = Sep 18? Actually careful: If we count backwards inclusively, the day before Kalends is pridie = ante diem II, which is Sep 30. So ante diem XIV means the 14th day before, i.e., 13 days before the 1st, so it's Sep 18? Let's compute: Oct 1 minus 13 days = Sep 18 (since Sep has 30 days, Oct 1 -1 = Sep30, -2 = Sep29, ... -13 = Sep18). Yes.

Similarly, for "ante diem N Nonas", we count backwards from the Nones day. For "ante diem N Idus", count backwards from Ides.
