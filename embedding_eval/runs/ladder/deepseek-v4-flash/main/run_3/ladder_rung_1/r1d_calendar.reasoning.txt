Day-of-year: Jun6=157 (as earlier). Nov22: Nov1=305, Nov22=305+21=326. So start=157, end=326, D=326-157+1=170 days.

Start s: (157+2)=159 mod7=5 (Friday). D=170, r=170%7=170-7*24=170-168=2. Full weeks=24, remainder 2: s=5(Fri),6(Sat). So remainder includes Fri, Sat. Weekdays in remainder: Fri only (1). So business days = 24*5 + 1 = 120+1=121. Also weekends: full weeks 24*2=48, remainder Sat (1), total weekends=49, weekdays=170-49=121. So answer: 121.

Thus Q50: 121.
