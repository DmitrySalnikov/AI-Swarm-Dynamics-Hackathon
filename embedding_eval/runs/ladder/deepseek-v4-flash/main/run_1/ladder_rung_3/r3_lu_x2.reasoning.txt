We need to output first the entries of L strictly below the diagonal row by row (i.e., L21, L31, L32, L41, L42, L43, ... up to L10,1 ... L10,9) then the entries of U on and above the diagonal row by row (U11, U12, ..., U1,10; U22, ..., U2,10; ...; U10,10). The answer should be a comma-separated list of integers.

We need to compute LU without pivoting. This means we use the natural order: pivot on diagonal entries at each step. The process: for each column k from 1 to n-1, for each row i > k, compute multiplier L_ik = A_ik / A_kk (where A refers to current matrix undergoing elimination), then subtract L_ik times row k from row i to zero out column k below diagonal. The multipliers become entries of L, and the final upper triangular matrix is U.

We must ensure that all intermediate entries, including the pivots, are such that division yields integer L_ik (since L entries are integers, and U entries are integers). The problem says all entries of L and U are integers, so the multipliers must be integers and all elimination yields integer results.
