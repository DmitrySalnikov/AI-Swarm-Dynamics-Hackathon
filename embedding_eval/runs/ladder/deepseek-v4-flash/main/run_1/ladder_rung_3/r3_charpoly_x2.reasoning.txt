We are given a 5x5 matrix A. We need to compute the characteristic polynomial p(x) = det(xI - A) = x^5 + c4 x^4 + c3 x^3 + c2 x^2 + c1 x + c0. We need to output all six coefficients in order: 1, c4, c3, c2, c1, c0, as a comma-separated list of integers. So we need to compute these coefficients exactly.

We can compute the characteristic polynomial by a variety of methods: determinant expansion, using trace and other invariants (like sums of principal minors), or by direct computation with numbers. Since it's 5x5, we can do it by hand with careful arithmetic, or use some systematic approach. Since the matrix entries are small integers, we can compute the characteristic polynomial using the method of computing the determinant of xI - A symbolically by performing row operations or expansion. Alternatively, we can compute the coefficients using the fact that for a matrix, the characteristic polynomial coefficients are (up to sign) the elementary symmetric sums of eigenvalues, which can be expressed in terms of traces of powers, but that might be messy.

Better: compute det(xI - A) directly by performing Gaussian elimination or by using the formula for the determinant via expansion. Since it's a 5x5, we could compute using minors. Alternatively, we can compute the characteristic polynomial using the Faddeev–LeVerrier algorithm (also known as the method of traces). That algorithm uses the traces of powers of A to compute the coefficients recursively. For a matrix of size n, we have:

Let A be n×n. Define p(λ) = det(λI - A) = λ^n + c_{n-1} λ^{n-1} + ... + c0.

The algorithm:
Let M_k = A^k (we need traces of powers)
Define c_{n-1} = - trace(A)
Then compute recursively:
For k = 1 to n-1:
    B_k = A * (M_{k-1} + c_{n-1} I?) Actually there's a known recurrence.

Standard Faddeev–LeVerrier algorithm:
Initial: B_0 = I, c_n = 1
For k = 1 to n:
    M_k = A * B_{k-1}
    c_{n-k} = - (1/k) trace(M_k)
    B_k = M_k + c_{n-k} I
Then p(λ) = λ^n + c_{n-1} λ^{n-1} + ... + c0.

But careful: The sign conventions vary. Usually, characteristic polynomial is det(λI - A) = λ^n - (tr A) λ^{n-1} + ... + (-1)^n det(A). With the algorithm above, if we define p(λ) = det(λI - A), then the coefficients are given by the recurrence: 
Let B_0 = I, c_n = 1.
For k=1..n:
   M_k = A * B_{k-1}
   c_{n-k} = - (1/k) trace(M_k)
   B_k = M_k + c_{n-k} I
Then p(λ) = c_n λ^n + c_{n-1} λ^{n-1} + ... + c_0.

So c_n = 1, c_{n-1} = - trace(A), c_{n-2} = -1/2 trace(A B_1)? Actually B_1 = A + c_{n-1}I, etc.
