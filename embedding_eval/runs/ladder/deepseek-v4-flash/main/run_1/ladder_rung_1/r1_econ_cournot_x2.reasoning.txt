We are given 150 firms competing in quantities (Cournot). Inverse demand: P = 5624 - 3Q, where Q = sum q_i. Each firm i has constant marginal cost c_i (list provided). They choose quantities simultaneously to maximize profit (P - c_i) q_i. We need to find the Nash equilibrium market price P. Since there are many firms with different costs, some firms may produce zero if their cost is too high relative to the equilibrium price. We need to jointly determine which firms are active and the equilibrium quantity for each. In Cournot with linear demand and constant marginal costs, the equilibrium can be found by solving the first-order conditions. For each active firm i, we have: P - c_i - q_i * (dP/dQ) = 0, where dP/dQ = -3. So condition: P - c_i - 3 q_i = 0 => q_i = (P - c_i)/3, provided P > c_i; if P <= c_i, then q_i = 0. So active firms are those with c_i < P. Then total quantity Q = sum_{i: c_i < P} (P - c_i)/3. Also market price P = 5624 - 3Q. So we have an equation: P = 5624 - 3 * sum_{i: c_i < P} (P - c_i)/3 = 5624 - sum_{i: c_i < P} (P - c_i). So: P = 5624 - sum_{i: c_i < P} (P - c_i). Rearranging: P = 5624 - N_P * P + sum_{i: c_i < P} c_i, where N_P = number of firms with c_i < P. So: P + N_P * P = 5624 + sum_{i: c_i < P} c_i => P (1 + N_P) = 5624 + S_P, where S_P = sum of costs of firms with c_i < P. Then P = (5624 + S_P) / (1 + N_P). So the equilibrium price is a function of the set of active firms. This set is determined by the condition that all firms with cost below P are active, and those with cost above P are inactive (if cost equals P, they are indifferent; but since marginal cost constant, they can produce zero; we assume they produce zero if equal because profit would be zero anyway; but can treat as inactive). So we need to find P such that if we take all firms with c_i < P, then P computed as (5624 + sum c_i) / (1 + count) equals that same P. That is a fixed-point condition. Since costs are discrete, we can sort the costs, and find the threshold such that the formula yields a price that lies between the highest active cost and the next higher cost.
