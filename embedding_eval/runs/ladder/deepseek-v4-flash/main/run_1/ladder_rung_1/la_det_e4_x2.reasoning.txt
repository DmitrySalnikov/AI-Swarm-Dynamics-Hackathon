a^{(k)}_{i,j} = ( a^{(k-1)}_{k,k} * a^{(k-1)}_{i,j} - a^{(k-1)}_{i,k} * a^{(k-1)}_{k,j} ) / a^{(k-2)}_{k-1,k-1}   for i,j > k, with the convention a^{( -1)}_{0,0}=1. This yields exact integers. The determinant is a^{(n-1)}_{n,n}. This is known as the Bareiss algorithm (or fraction-free Gaussian elimination). It might be lengthy but doable by hand if we are systematic.
