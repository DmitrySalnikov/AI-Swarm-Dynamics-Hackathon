We are given 18 bodies in thermal contact inside a thermally insulated container. The final equilibrium temperature is between 0 and 100°C, and all ice melts and all steam condenses. So we need to compute the final temperature.

We have masses, initial temperatures, specific heats for solids, and for water in various phases: ice, liquid water, steam. We have latent heats for melting and vaporization. Since the container is insulated and of negligible heat capacity, the total heat exchange is zero.

We need to sum the heat gains/losses for all bodies to reach a common final temperature T (in °C). We will set up an equation: sum of Q_i = 0, where Q_i = m_i * c_i * (T - T_i) for bodies that don't change phase (including liquid water), but for ice we need to account for melting: ice at -10°C must warm to 0°C, then melt, then the resulting water warms to T. For steam: steam at given temperature must cool to 100°C, then condense, then the resulting water cools to T. So we need to compute the heat contributions accordingly.

Let's list all bodies with their properties.

We'll compute contributions in terms of T (final temperature in °C). We'll set reference: heat added to a body is positive if it gains heat. So Q = m c (T_final - T_initial) for sensible heat. For phase changes, we add latent heat: for melting ice, heat added = m * L_f; for condensation of steam, heat released = - m * L_v (since steam loses heat). But careful: In our equation sum Q = 0, we can treat each body's net heat as: for ice: Q_ice = [heat to warm ice from T_i to 0°C] + [heat to melt ice] + [heat to warm resulting water from 0°C to T]. For steam: Q_steam = [heat to cool steam from T_i to 100°C] + [heat to condense steam] + [heat to cool resulting water from 100°C to T]. All these are positive if the body gains heat, but in reality ice will gain heat (positive Q) and steam will lose heat (negative Q). So we must be careful with signs: For ice warming: Q = m_ice * c_ice * (0 - T_ice), with T_ice negative, so (0 - (-10))=10, positive. Melting: Q = m_ice * L_f (positive). Then water warming: Q = m_ice * c_water * (T - 0) = m_ice * c_water * T. So total Q_ice = m_ice [c_ice*(0 - T_ice) + L_f + c_water * T]. For steam: cooling from T_steam to 100°C: Q = m_steam * c_steam * (100 - T_steam). Since T_steam > 100, this is negative. Actually careful: Q = m c (T_final - T_initial). For steam cooling from 138°C to 100°C: T_final=100, T_initial=138 => (100-138) = -38, so Q = m*2010*(-38) negative. Then condensation: Q = - m * L_v (since water loses heat). Then cooling water from 100°C to T: Q = m * c_water * (T - 100). So total Q_steam = m_steam [c_steam*(100 - T_steam) - L_v + c_water*(T - 100)]. Actually we can write: Q_steam = m_steam * [c_steam*(100 - T_steam) - L_v + c_water*(T - 100)]. Since T < 100 likely, (T-100) is negative, so that term is negative. So overall Q_steam is negative (heat lost).

For solids and liquid water (no phase change): Q = m * c * (T - T_i). For liquid water, c = 4186 J/(kg·K). For solids, given specific heats.

We need to compute sum of all Q_i = 0, solve for T.

For each body i, we compute Q_i = m_i * c_i * (T - T_i) for no phase change; for ice and steam we use the more complex expressions. Then sum = 0.

We can group terms by coefficient of T and constant terms. Write Q_total = A * T + B = 0, so T = -B/A.

We'll compute A: sum of m_i * c_i for all bodies that have sensible heat term proportional to T. That includes: all solids (including the glass, brass, copper, lead, granite, zinc, iron) plus all liquid water (including the water from melted ice and condensed steam). But careful: For ice, the contribution from the melted water is m_ice * c_water * T. For steam, the contribution from the condensed water is m_steam * c_water * T. So we need to include those in the overall A. Also for liquid water bodies already present: m * c_water. So total coefficient A = sum over all bodies: (m_i * c_i_effective), where for solids and liquid water it's m * c, for ice it's m_ice * c_water, for steam it's m_steam * c_water. But note: For ice, there is also the warming of ice itself (which doesn't involve T) and melting; for steam, cooling and condensation do not involve T. So those will go into constant B.

Also, note that for some solids, we have c given, so we include them with their c. For liquid water, c=4186. For the melted ice water and condensed steam water, c=4186.

Now compute constant term B: sum of all contributions that do not involve T. For each body, Q = m*c*(T - T_i) => contributes - m*c*T_i to constant when we write Q = m*c*T - m*c*T_i. So for bodies with no phase change, the constant part is - m*c*T_i. For ice, we have additional constants: warming ice from T_i to 0, and melting. That is: m_ice * [c_ice*(0 - T_i) + L_f]. Note that T_i = -10°C, so (0 - (-10)) = 10, so warming: m_ice * c_ice * 10. And melting: m_ice * L_f. So constant from ice = m_ice * (c_ice*10 + L_f) but also note that the water part gives - m_ice * c_water * 0? Actually the T term is m_ice*c_water*T, but the constant from that term is - m_ice*c_water*0 = 0. So no constant from that. So constant from ice is only the warming and melting. However, we must also consider that the ice has a negative initial temperature, but the sensible heat for the ice itself is computed as m_ice*c_ice*(0 - T_i) = positive constant. So it's all in constant.

For steam: Q_steam = m_steam [c_steam*(100 - T_steam) - L_v + c_water*(T - 100)]. Expand: = m_steam*c_water*T + m_steam [c_steam*(100 - T_steam) - L_v - c_water*100]. So the constant part from steam is m_steam [c_steam*(100 - T_steam) - L_v - 100*c_water]. Because the T term gives m_steam*c_water*T, and the constant is the remainder. So we can compute constant = m_steam * (c_steam*(100 - T_steam) - L_v - 100*c_water). Note that (100 - T_steam) is negative, so c_steam*(100 - T_steam) is negative. So overall constant is negative.
