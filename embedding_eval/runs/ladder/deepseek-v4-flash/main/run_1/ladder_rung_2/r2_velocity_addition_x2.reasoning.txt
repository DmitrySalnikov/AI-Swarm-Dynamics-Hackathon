We are given a series of relative velocities between successive inertial frames S0, S1, ..., S60. All frames have parallel axes and move along their common x-axis. The velocities given are in units of c (so the speed of light c = 1). We need to find the velocity of S60 relative to S0.

Since each velocity is given relative to the previous frame, we need to compose them using relativistic velocity addition. The relativistic velocity addition formula for one-dimensional motion: if frame S' moves with velocity v1 relative to S, and S'' moves with velocity v2 relative to S', then the velocity of S'' relative to S is v = (v1 + v2) / (1 + v1 v2). In units where c=1.

So we need to compose the sequence of 60 velocities: v_{0->1} = -3/11, v_{1->2}=1/5, v_{2->3}=-3/11, etc. The composition is associative and can be done stepwise. However, there might be a pattern or simplification using hyperbolic tangent addition, because relativistic velocity addition corresponds to addition of rapidities: rapidity θ = artanh(v), and v = tanh(θ). Then composition is just addition of rapidities: θ_total = Σ θ_i. So we can compute rapidities for each given velocity, sum them, and then compute tanh of the sum to get the final velocity.

That is easier: compute θ_i = artanh(v_i) = (1/2) ln((1+v_i)/(1-v_i)). Then total rapidity Θ = Σ θ_i, then v_total = tanh(Θ). But we need exact rational result? The velocities are rational fractions.
