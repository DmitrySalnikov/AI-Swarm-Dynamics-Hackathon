We need to compute 47 Doppler effect frequencies. There are three types: observer moving relative to stationary source, source moving relative to stationary observer, both moving, and reflector cases. All speeds are given in m/s, sound speed v = 343 m/s in still air.

General formulas:
For sound, the observed frequency f' = f * (v ± v_o) / (v ∓ v_s), where signs: numerator: + if observer moves toward source, - if away; denominator: - if source moves toward observer, + if away. Standard: if source and observer approach each other, frequency increases.

For reflector: The sound travels from source to reflector, then reflects back to source (or maybe to observer? In these problems, it says "frequency of the reflected sound received back at the source." So source is stationary, reflector moves. The sound hits the moving reflector, which then acts as a moving source emitting the frequency it receives. So we do two Doppler shifts: first, source stationary, reflector as observer moving, so frequency received by reflector f_r = f * (v ± v_r)/v? Wait careful: For source stationary, observer moving: f_obs = f * (v ± v_o)/v, where sign: + if observer moves toward source, - if away. Here reflector is moving toward source, so it's approaching source: so f_r = f * (v + v_r)/v (since v_o = v_r toward source). Then reflector re-emits sound as a moving source, and the original source (now acting as observer) is stationary. So frequency heard back at source: f' = f_r * v/(v ∓ v_s), where v_s is speed of source (reflector) relative to medium. Since reflector is moving, it's a moving source. The source (original) is stationary observer. For the reflector moving towards the source, then when it re-emits, it is moving toward the stationary observer (the original source), so the denominator uses minus: f' = f_r * v/(v - v_r). So overall, f' = f * (v + v_r)/v * v/(v - v_r) = f * (v + v_r)/(v - v_r). If reflector moves away from source, then first: reflector moving away from source, so f_r = f * (v - v_r)/v (since observer moving away), then reflector re-emits as source moving away from observer (original source), so f' = f_r * v/(v + v_r) = f * (v - v_r)/(v + v_r). So for reflector moving toward source: f' = f * (v + v_r)/(v - v_r). For reflector moving away: f' = f * (v - v_r)/(v + v_r).

So for problems with reflector, we'll use these formulas.
