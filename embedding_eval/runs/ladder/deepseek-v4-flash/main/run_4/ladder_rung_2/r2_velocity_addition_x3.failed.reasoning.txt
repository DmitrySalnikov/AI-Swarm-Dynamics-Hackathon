We have to combine velocities using relativistic velocity addition formula: if frame S_i moves with velocity v_i relative to S_{i-1}, then the velocity of S_n relative to S_0 is given by repeated relativistic addition. For velocities along a line, the composition is given by: u ⊕ v = (u+v)/(1+u v/c^2). Since we are using units where c=1 (velocities given as fractions, presumably in units of c, so we treat them as β = v/c), the formula becomes: β_total = (β1 + β2) / (1 + β1 β2) for two successive velocities. For many, we can add sequentially: β^{(n)} = (β^{(n-1)} + β_n) / (1 + β^{(n-1)} β_n).

We can think of using rapidity addition, because relativistic velocities add linearly when expressed in terms of rapidity. The rapidity θ is defined by β = tanh θ. Then for successive boosts along the same axis, rapidities add: θ_total = θ1 + θ2 + ... + θn. So the final β = tanh(∑ θ_i). So we can compute the sum of rapidities corresponding to each velocity, then take tanh of the sum. That might be simpler because we can sum many rational numbers if we express each θ as artanh(β). But artanh(β) = (1/2) ln((1+β)/(1-β)). So the sum of rapidities is (1/2) ln(∏ (1+β_i)/(1-β_i)). Then tanh of sum = (exp(2∑θ)-1)/(exp(2∑θ)+1) = (∏ (1+β_i)/(1-β_i) - 1) / (∏ (1+β_i)/(1-β_i) + 1). So we can compute the product of factors (1+β_i)/(1-β_i) and then the final velocity = (P-1)/(P+1), where P = ∏_{i=1}^{60} (1+β_i)/(1-β_i). Since β_i are rational numbers, P is rational, and then final β = (P-1)/(P+1). That yields a rational fraction. So we can compute product step by step, possibly simplifying fractions.
