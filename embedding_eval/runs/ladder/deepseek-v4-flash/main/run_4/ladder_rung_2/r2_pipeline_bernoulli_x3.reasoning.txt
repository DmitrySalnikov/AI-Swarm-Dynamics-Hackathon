But note: Δp_loss is the pressure drop due to the connection, so it's an additional loss that appears on the right side (or subtracted from left). Typically, Bernoulli with loss: p1 + (1/2)ρ v1^2 + ρgz1 = p2 + (1/2)ρ v2^2 + ρgz2 + h_loss * ρg, where h_loss = K * v1^2/(2g). Then Δp_loss = ρ g h_loss = ρ * K * v1^2/2. So it's consistent.

Thus we can write for each step:

p_i + (1/2)ρ v_i^2 + ρ g z_i = p_{i+1} + (1/2)ρ v_{i+1}^2 + ρ g z_{i+1} + K_i * (1/2)ρ v_i^2.

So rearranging:

p_{i+1} = p_i + (1/2)ρ (v_i^2 - v_{i+1}^2) + ρ g (z_i - z_{i+1}) - K_i * (1/2)ρ v_i^2.
