We are asked to find the signature (p, q) of the quadratic form Q(x) = x^T A x, where A is a 7x7 symmetric integer matrix. We need to determine the number of positive and negative eigenvalues (or equivalently, the index of inertia). Since it's a real symmetric matrix, the signature is (p, q, zero) where p = number of positive eigenvalues, q = number of negative eigenvalues, and zero = 7 - p - q. We need p and q.

We can compute the eigenvalues or perform Gaussian elimination with complete squares (Lagrange method) to find the diagonal form with coefficients ±1 or at least sign counts. But doing it by hand for a 7x7 matrix might be tedious but possible with systematic row/column operations that preserve inertia (i.e., congruence transformations). Since A is symmetric, we can perform simultaneous row and column operations (like Gaussian elimination but with symmetric operations) to diagonalize it over reals. The inertia is preserved under congruence: P^T A P with invertible P. So we can perform elementary row and column operations (the same operations on rows and columns) to reduce A to a diagonal matrix D, and then count signs of diagonal entries. However, careful: when we use row operations that are not orthogonal, we need to apply the same operation to rows and columns (i.e., if we do an elementary row operation, we must do the corresponding column operation to maintain symmetry). This is essentially performing LDL^T decomposition, where D is diagonal and L is lower triangular with ones on diagonal. We can do this using elimination: for each step, we choose a pivot (nonzero diagonal entry or some other) and eliminate other entries in that row/column.
