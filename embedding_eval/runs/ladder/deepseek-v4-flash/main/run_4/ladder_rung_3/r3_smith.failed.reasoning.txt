We can compute SNF by performing integer row and column operations: swap rows/cols, add multiples of one row to another, multiply row by -1 (unit). The process: reduce to diagonal form by successive elimination.

Alternatively, we can compute using the theory: invariant factors are the ratios of successive determinantal divisors (gcd of all k×k minors). But for 6x6, maybe easier to do elimination step-by-step systematically.
