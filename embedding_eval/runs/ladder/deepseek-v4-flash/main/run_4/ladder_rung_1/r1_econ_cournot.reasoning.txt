We are given 176 firms with constant marginal costs. They compete in Cournot (quantity competition). Inverse demand: P = 7861 - 5Q, where Q = total quantity. Each firm chooses q_i >= 0 to maximize profit (P - c_i) q_i. Since costs differ, some firms may produce zero in equilibrium (if their cost is too high). We need to find Nash equilibrium market price P.

In Cournot equilibrium with linear demand and constant marginal costs, we have a well-known characterization: For each firm i, if it produces positive quantity, its first-order condition is: P + q_i * dP/dQ = c_i. Since dP/dQ = -5, we have P - 5 q_i = c_i => q_i = (P - c_i)/5, provided P > c_i. If P <= c_i, then firm produces zero. So in equilibrium, only firms with cost below the equilibrium price produce positive quantities. The total quantity Q = sum_{i: c_i < P} (P - c_i)/5. Also, P = 7861 - 5Q. So we have:

P = 7861 - 5 * [ sum_{i: c_i < P} (P - c_i)/5 ] = 7861 - sum_{i: c_i < P} (P - c_i) = 7861 - [ n(P) * P - sum_{i: c_i < P} c_i ], where n(P) is the number of firms with c_i < P. So:

P = 7861 - n(P) P + S(P), where S(P) = sum_{i: c_i < P} c_i.

Thus, bring terms: P + n(P) P = 7861 + S(P) => P (1 + n(P)) = 7861 + S(P) => P = (7861 + S(P)) / (1 + n(P)).

So the equilibrium price must satisfy that equation, where n(P) and S(P) are determined by the set of firms with cost less than P. This is a fixed point: We need to find P such that if we take all firms with cost < P, then the formula yields P. Also we must ensure that firms with cost exactly equal to P would produce zero (since then q_i = (P - c_i)/5 = 0, so it's fine to include them or not; but usually we treat them as indifferent; but since costs are given as integers, we can check if any c_i equals P). So we need to find P consistent.
