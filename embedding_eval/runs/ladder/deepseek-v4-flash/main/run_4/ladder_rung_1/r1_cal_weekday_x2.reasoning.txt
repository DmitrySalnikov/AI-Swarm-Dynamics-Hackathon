We are asked to find the day of the week for 64 dates in the Gregorian calendar. The Gregorian calendar rules: leap years are years divisible by 4, except years divisible by 100 that are not divisible by 400. So we need to compute the weekday for each date. Since there are many dates, we need an efficient method. We can use Zeller's congruence or a known reference. Since we are to provide answers in order, we can compute each one.

We can use the formula: For Gregorian calendar, the day of week for a given date can be computed using:

For month m, day d, year y (with January and February counted as months 13 and 14 of previous year), the formula (Zeller's congruence) is:

h = (d + floor(13*(m+1)/5) + K + floor(K/4) + floor(J/4) - 2*J) mod 7

where:
- m = month number, with March=3, April=4, ..., January=13, February=14 of previous year.
- If month is January or February, then year = y-1, else year = y.
- J = century (floor(year/100))
- K = year within century (year mod 100)

Then h: 0=Saturday, 1=Sunday, 2=Monday, 3=Tuesday, 4=Wednesday, 5=Thursday, 6=Friday? Actually there are different conventions. We need consistent mapping. Standard Zeller: h = (d + floor(13*(m+1)/5) + K + floor(K/4) + floor(J/4) + 5J) mod 7 or -2J? Let's recall: For Gregorian, the formula is:

h = (d + floor((13*(m+1))/5) + K + floor(K/4) + floor(J/4) + 5J) mod 7? Actually common formula: h = (d + floor(13*(m+1)/5) + K + floor(K/4) + floor(J/4) - 2J) mod 7, with h: 0=Saturday,1=Sunday,...6=Friday. But we can also use: h = (d + floor((13*(m+1))/5) + K + floor(K/4) + floor(J/4) + 5*J) mod 7, then 0=Saturday? Let's derive clearly.

Alternative: There is known method: For Gregorian, the doomsday algorithm is also efficient. But since we need many dates, we can compute systematically.

Alternatively, we can use known reference points: For example, we know that 1 Jan 2000 was a Saturday. But we have many years across centuries. It might be easier to use a programmatic approach in mind, but we must do manually. We can compute each date using a consistent algorithm.

Let's adopt Zeller's congruence with the following mapping (common in many texts):
Let h = (d + floor((13*(m+1))/5) + K + floor(K/4) + floor(J/4) + 5J) mod 7, where h = 0 => Saturday, 1 => Sunday, 2 => Monday, 3 => Tuesday, 4 => Wednesday, 5 => Thursday, 6 => Friday. But careful: Many use a different mapping. Let's verify with a known date: For example, 1 Jan 2000: m=13 (Jan), year=1999 (since Jan of 2000 becomes month 13 of previous year), so J=19, K=99. Then compute:
d=1, m=13 => (13*(m+1))/5? Actually m+1=14, 13*14=182, floor(182/5)=36.4? Actually 182/5=36.4, floor=36. K=99, floor(K/4)=24, floor(J/4)=4, 5J=95. Sum: 1+36+99+24+4+95 = 259. 259 mod 7 = 259 - 7*37=259-259=0 -> Saturday. That matches: 1 Jan 2000 was Saturday. So mapping works: 0=Saturday,1=Sunday,...6=Friday. So we'll use that.
