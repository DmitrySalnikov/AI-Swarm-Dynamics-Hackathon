We need to find the Cournot equilibrium with 150 firms, each with constant marginal cost c_i given. The inverse demand: P = 5624 - 3Q, where Q = sum q_i.

In Cournot competition, each firm i chooses q_i to maximize profit π_i = (P - c_i) q_i, taking others' quantities as given. The first-order condition: P + q_i * dP/dQ - c_i = 0. Since dP/dQ = -3, we have: P - 3q_i - c_i = 0 => q_i = (P - c_i)/3, provided that P > c_i, else q_i=0.

Also, the market price P must satisfy the inverse demand: P = 5624 - 3Q, where Q = sum q_i.

Thus, we have a system where for each firm with c_i < P, q_i = (P - c_i)/3; for c_i >= P, q_i = 0. Then Q = sum_{i: c_i < P} (P - c_i)/3 = (1/3) * [ N(P)*P - sum_{i: c_i < P} c_i ], where N(P) is the number of firms with c_i < P.

Then the market price also satisfies P = 5624 - 3Q = 5624 - 3*(1/3)*[ N(P)*P - S(P) ] = 5624 - [ N(P)*P - S(P) ], where S(P) = sum_{i: c_i < P} c_i.

Thus, we have:

P = 5624 - N(P)*P + S(P)

=> P + N(P)*P = 5624 + S(P)

=> P (1 + N(P)) = 5624 + S(P)

=> P = (5624 + S(P)) / (1 + N(P))
