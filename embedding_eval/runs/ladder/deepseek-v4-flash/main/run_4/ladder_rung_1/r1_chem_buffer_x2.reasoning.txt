We need to be careful: The "acid form" is the protonated form, "base form" is the deprotonated form. For example, for lactic acid, acid form is lactic acid (HLac), base form is lactate (Lac-). For benzoic acid: acid = benzoic acid (HBz), base = benzoate (Bz-). For TRIS: TRIS-H+ is the acid form, TRIS base is the base form. For ammonium: NH4+ is acid, NH3 is base. We calculate mmol = concentration (M) * volume (mL) = mmol directly since 1 M * 1 mL = 1 mmol.

For mixtures, total volume is irrelevant for ratio because both forms are in same volume. So we just compute amounts in mmol.

Then apply addition: For HCl added, it converts base form to acid form: base form decreases by amount of HCl, acid form increases by same amount. For NaOH added, it converts acid form to base form: acid decreases, base increases. Must ensure we don't have negative amounts after addition; but typically the added amount is less than the initial amounts, so it's fine.

After adjustment, compute ratio = n_base / n_acid. Then pH = pKa + log10(ratio). If ratio is zero or infinite, that would be problematic, but we assume all are within buffer range.
