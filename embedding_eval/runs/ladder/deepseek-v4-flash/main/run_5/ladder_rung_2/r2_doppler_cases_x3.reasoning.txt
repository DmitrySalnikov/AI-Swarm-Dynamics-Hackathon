We'll handle each case using the Doppler formula for sound. The general formula for observed frequency f' when source and observer are moving relative to the medium (air) is:

f' = f * (v + v_o) / (v + v_s)   (with sign conventions)

Where:
v = speed of sound = 343 m/s.
v_o = speed of observer relative to medium; positive if observer moves toward source (since that increases the perceived frequency), negative if away.
v_s = speed of source relative to medium; positive if source moves away from observer (since that decreases frequency), negative if toward observer.

But careful: Many textbooks use: f' = f * (v ± v_o) / (v ∓ v_s), where signs depend on direction. To avoid confusion, we'll use: 
If observer moves toward source: v_o positive; away: v_o negative.
If source moves toward observer: v_s negative; away: v_s positive.

Thus: f' = f * (v + v_o) / (v + v_s) where v_s is signed as above.

Alternative: f' = f * (v + v_o)/(v - v_s') where v_s' is speed of source with sign opposite? Let's just stick to the signed convention: v_o positive if observer moving toward source (i.e., closing speed increases frequency), v_s positive if source moving away from observer (i.e., opening speed decreases frequency). So formula: f_observed = f_source * (v + v_o) / (v + v_s). That works.

For reflector cases: The sound from a stationary source hits a moving reflector. The reflector acts as a moving observer receiving the sound, then re-emits as a moving source. If the reflector moves toward the source, then the observer is moving toward the source, so v_o positive, frequency increases. If away, v_o negative. So f_r = f * (v + v_o_r) / v, where v_o_r = +v_r if moving toward source, -v_r if moving away.

Then the reflector re-emits that frequency as a moving source. The sound goes back to the original source location (which is stationary). So now we have a moving source (reflector) and stationary observer (original source). For this second shift: source (reflector) moves with speed v_r (now as source) and observer stationary. Sign: if the reflector is moving away from the stationary source (the original source), then the source (reflector) is moving away from the observer, so v_s positive (since it's away from observer), which decreases frequency. If moving toward, v_s negative. So f_final = f_r * v / (v + v_s), where v_s = +v_r if moving away from observer (the source location), -v_r if moving toward.

Thus overall: f_final = f * (v + v_o_r) / v * v / (v + v_s) = f * (v + v_o_r) / (v + v_s). But careful: v_o_r is for reflector as observer relative to source; v_s is for reflector as source relative to original source. They are related: if reflector moves away from source, then for reception: observer (reflector) is moving away from source, so v_o_r = -v_r; for emission: source (reflector) is moving away from observer (original source), so v_s = +v_r. So then f_final = f * (v - v_r) / (v + v_r). If reflector moves toward source: reception: observer moving toward source => v_o_r = +v_r; emission: source moving toward observer => v_s = -v_r; thus f_final = f * (v + v_r) / (v - v_r). So the formula for reflected sound received back at source is:

If reflector moves toward source: f_reflected = f * (v + v_r) / (v - v_r)
If reflector moves away from source: f_reflected = f * (v - v_r) / (v + v_r)

Alternatively, we can combine as: f_reflected = f * (v ± v_r) / (v ∓ v_r), with top sign for toward.

Thus we have straightforward computations.
