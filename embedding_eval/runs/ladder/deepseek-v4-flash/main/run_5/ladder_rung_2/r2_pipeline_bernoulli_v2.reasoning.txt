So we can compute velocities in each section: v_i = Q / A_i.

The flow is incompressible and steady. The Bernoulli equation with head loss: between section i and i+1, the total pressure (p + ρv²/2 + ρgz) is reduced by the loss Δp_loss. So we have:

p_i + ρ v_i^2/2 + ρ g z_i = p_{i+1} + ρ v_{i+1}^2/2 + ρ g z_{i+1} + Δp_loss_i, where Δp_loss_i = K_i * (ρ v_i^2/2).
