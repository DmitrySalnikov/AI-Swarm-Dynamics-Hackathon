We are given a 7x7 integer matrix A with eigenvalue 1 only. So the characteristic polynomial is (λ-1)^7, but the Jordan form consists of Jordan blocks of eigenvalue 1 with various sizes summing to 7. We need to determine the Jordan normal form, i.e., the sizes of the Jordan blocks. The order: by eigenvalue increasing, but all eigenvalues are 1; for equal eigenvalues, by block size in decreasing order. So we need to list the sizes in descending order. So we need to compute the Jordan block sizes, i.e., the partition of 7.

We must compute the Jordan form from the matrix A. Typically we need to find the nullities of (A - I)^k for k=1,2,... to determine the sizes. Since eigenvalue is 1, we compute N_k = nullity((A - I)^k). The difference sequence gives the number of blocks of size at least k. Or we can compute the dimensions of the generalized eigenspaces.

Let B = A - I. Then A = I + B, and B is nilpotent. We need the Jordan form of B (nilpotent). The sizes of Jordan blocks for B are the same as for A. So we compute the ranks (or nullities) of B^k.

We need to compute nullities of B, B^2, B^3,... up to 7. Since B is 7x7 nilpotent, its index of nilpotency is at most 7. We can compute ranks using row reduction or use computational approach (by hand or systematic). Given it's a contest problem, we can likely compute step by step.

We need to find the Jordan block sizes. Let d_k = nullity(B^k). Then number of blocks of size at least k is d_k - d_{k-1} (with d_0=0). And number of blocks of size exactly k is (d_k - d_{k-1}) - (d_{k+1} - d_k) = 2d_k - d_{k-1} - d_{k+1}. So we need d1 = nullity(B), d2 = nullity(B^2), etc.

Alternatively, compute the rank of B^k: rank(B^k) = n - nullity(B^k). So we can compute ranks.
