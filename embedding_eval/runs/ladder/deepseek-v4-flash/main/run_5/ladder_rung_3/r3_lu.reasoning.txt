The decomposition exists and is unique, and all entries are integers. We must output first the entries of L strictly below the diagonal, row by row (i.e., for i=2: L21; i=3: L31, L32; i=4: L41, L42, L43; ...; i=10: L101,...,L109), then the entries of U on and above the diagonal row by row (U11, U12,...,U1,10; U22,...,U2,10; ...; U10,10). All as a comma-separated list of integers.

So we can implement Gaussian elimination without row swaps.

Let's denote the matrix A. We'll compute U and L stepwise. We'll treat A as a 10x10 array. The algorithm: For k=1 to n-1, for i=k+1 to n: compute L_{ik} = A_{ik} / A_{kk} (since A is being transformed to U, we need to store L). Then update A_{i,j} for j=k+1 to n: A_{i,j} -= L_{ik} * A_{k,j}. The A matrix after the algorithm becomes U, and L is the lower-triangular matrix with 1 on diagonal and the multipliers.

But we must ensure we use integer arithmetic; since all entries are integers and the decomposition is integer, the multipliers should be integers as well. So A_{kk} must divide A_{ik} exactly.
