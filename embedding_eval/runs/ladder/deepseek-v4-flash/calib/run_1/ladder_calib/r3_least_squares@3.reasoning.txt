We are given a 5x3 matrix A and a vector b. Need to find least-squares solution x that minimizes ||Ax - b||^2. The columns of A are linearly independent, so the normal equations A^T A x = A^T b have a unique solution.

We can compute A^T A and A^T b explicitly, then solve the 3x3 system.

Given A:

Row1: [0, 1, -2]
Row2: [0, 1, -1]
Row3: [1, -1, 1]
Row4: [1, 0, 0]
Row5: [-1, 2, -1]

So A is 5x3.

b = [4, 0, 2, 2, 4]^T.

Compute A^T A: A^T times A.

First compute A^T:

A^T is 3x5:

Column1: from rows: (0,0,1,1,-1) but careful: transpose: rows become columns. So A^T = 
[0,0,1,1,-1;
 1,1,-1,0,2;
 -2,-1,1,0,-1]

But better: A^T = 
Row1: (0,0,1,1,-1)
Row2: (1,1,-1,0,2)
Row3: (-2,-1,1,0,-1)

Now compute A^T A = A^T * A (3x5 * 5x3 = 3x3). Compute each entry:

Let’s denote A columns: c1, c2, c3 are columns of A (5x1). Actually A^T A has entries (i,j) = dot product of column i and column j of A. That might be easier: Since A^T A = [c_i^T c_j]. So compute dot products between columns of A.

Columns of A:

col1 = (0,0,1,1,-1)^T
col2 = (1,1,-1,0,2)^T
col3 = (-2,-1,1,0,-1)^T

Now compute dot products:

c1·c1 = 0^2+0^2+1^2+1^2+(-1)^2 = 0+0+1+1+1 = 3.
c1·c2 = 0*1 +0*1 +1*(-1)+1*0+(-1)*2 = 0+0-1+0-2 = -3.
c1·c3 = 0*(-2)+0*(-1)+1*1+1*0+(-1)*(-1) = 0+0+1+0+1 = 2.
c2·c1 = same -3.
c2·c2 = 1^2+1^2+(-1)^2+0^2+2^2 = 1+1+1+0+4 = 7.
c2·c3 = 1*(-2)+1*(-1)+(-1)*1+0*0+2*(-1) = -2 -1 -1 +0 -2 = -6.
c3·c1 = 2.
c3·c2 = -6.
c3·c3 = (-2)^2+(-1)^2+1^2+0^2+(-1)^2 = 4+1+1+0+1 = 7.

So A^T A = [[3, -3, 2],
            [-3, 7, -6],
            [2, -6, 7]].

Now compute A^T b: A^T b = [c1·b, c2·b, c3·b]^T.

b = (4,0,2,2,4)^T.

Compute:

c1·b = 0*4 +0*0 +1*2 +1*2 +(-1)*4 = 0+0+2+2-4 = 0.
c2·b = 1*4 +1*0 +(-1)*2 +0*2 +2*4 = 4+0-2+0+8 = 10.
c3·b = (-2)*4 +(-1)*0 +1*2 +0*2 +(-1)*4 = -8+0+2+0-4 = -10.

So A^T b = [0, 10, -10]^T.

Thus normal equations: A^T A x = A^T b:

[3, -3, 2] [x1] = [0]
[-3,7,-6] [x2] = [10]
[2,-6,7] [x3] = [-10]

Solve this system. Write equations:

(1) 3x1 - 3x2 + 2x3 = 0
(2) -3x1 + 7x2 - 6x3 = 10
(3) 2x1 - 6x2 + 7x3 = -10

We can solve by elimination.

Add (1) and (2): (3x1 -3x2+2x3) + (-3x1+7x2-6x3) = 0+10 => 4x2 -4x3 = 10 => divide 2: 2x2 -2x3 =5 => 2(x2 - x3)=5 => x2 - x3 = 5/2. (Equation A)

Now eliminate x1 from (3) using (1) perhaps. Multiply (1) by something? Alternatively use (1) and (3). Solve (1) for x1: 3x1 = 3x2 -2x3 => x1 = x2 - (2/3)x3. Plug into (3): 2(x2 - (2/3)x3) -6x2 +7x3 = -10 => 2x2 - (4/3)x3 -6x2 +7x3 = -10 => -4x2 + (7 - 4/3)x3 = -10 => -4x2 + (21/3 -4/3)x3 = -10 => -4x2 + (17/3)x3 = -10. Multiply by 3: -12x2 + 17x3 = -30 => 12x2 -17x3 = 30. (Equation B)

Now we have Equation A: x2 - x3 = 5/2 => x2 = x3 + 5/2. Substitute into B: 12(x3 + 5/2) -17x3 = 30 => 12x3 + 30 -17x3 = 30 => -5x3 +30 =30 => -5x3 =0 => x3=0. Then x2 = 0 + 5/2 = 5/2. Then x1 = x2 - (2/3)x3 = 5/2 - 0 = 5/2.

So solution: x1 = 5/2, x2 = 5/2, x3 = 0.

But check if this satisfies all equations? (1) 3*(5/2)-3*(5/2)+2*0 = (15/2-15/2)=0 okay. (2) -3*(5/2)+7*(5/2)-6*0 = (-15/2+35/2)=20/2=10 okay. (3) 2*(5/2)-6*(5/2)+7*0 = (5 -15) = -10 okay. Good.

Thus least-squares solution x = [5/2, 5/2, 0]^T. So answer: 5/2, 5/2, 0. As comma-separated list: 5/2, 5/2, 0. But the problem says "exact numbers (integers or exact fractions a/b where needed)". So answer: 5/2, 5/2, 0. Could also write 2.5 but fractions preferred. So final: ANSWER: 5/2,5/2,0
