We are given a 3x3 integer matrix A:

A = 
[-1 -3 3]
[-1 3 -3]
[1 1 1]

We need to find its singular values. Singular values are the square roots of eigenvalues of A^T A (or A A^T). Since singular values are given to be integers, we can compute A^T A and find its eigenvalues. Then take square roots. Since singular values are non-negative, we list them in decreasing order, repeated according to multiplicity.

First compute A^T A.

A = 
[ -1, -3, 3 ]
[ -1, 3, -3 ]
[ 1, 1, 1 ]

Compute A^T:

A^T = 
[ -1, -1, 1 ]
[ -3, 3, 1 ]
[ 3, -3, 1 ]

Now compute A^T A = A^T * A. Let's do matrix multiplication.

Let’s denote rows of A^T or columns? Better compute (A^T A)_{ij} = sum_k (A^T)_{ik} A_{kj} = sum_k A_{ki} A_{kj}.

So for i and j from 1 to 3 (columns of A, rows of A^T). Since A is 3x3, A^T A is 3x3.

We'll compute dot products of columns of A.

Let columns of A be c1, c2, c3:

c1 = (-1, -1, 1)^T
c2 = (-3, 3, 1)^T
c3 = (3, -3, 1)^T

Then (A^T A)_{ij} = c_i · c_j.

So compute dot products:

c1·c1 = (-1)^2 + (-1)^2 + 1^2 = 1+1+1 = 3
c2·c2 = (-3)^2 + 3^2 + 1^2 = 9+9+1 = 19
c3·c3 = 3^2 + (-3)^2 + 1^2 = 9+9+1 = 19
c1·c2 = (-1)(-3) + (-1)(3) + (1)(1) = 3 -3 +1 = 1
c1·c3 = (-1)(3) + (-1)(-3) + (1)(1) = -3 +3 +1 = 1
c2·c3 = (-3)(3) + (3)(-3) + (1)(1) = -9 -9 +1 = -17

Thus A^T A = 
[ 3, 1, 1;
  1, 19, -17;
  1, -17, 19 ]

So matrix M = A^T A = 
[[3, 1, 1],
 [1, 19, -17],
 [1, -17, 19]].

Now find eigenvalues of this symmetric matrix. Then singular values are sqrt(eigenvalues). Since singular values are integers, eigenvalues must be perfect squares.

Compute eigenvalues. Let M = 
[3, 1, 1;
 1, 19, -17;
 1, -17, 19].

We can attempt to find characteristic polynomial: det(M - λI) = 0.

M - λI = 
[3-λ, 1, 1;
 1, 19-λ, -17;
 1, -17, 19-λ].

Compute determinant.

Let’s denote a = 3-λ, b = 19-λ. Then matrix is:
[ a, 1, 1;
  1, b, -17;
  1, -17, b ].

det = a * det([[b, -17],[-17, b]]) - 1 * det([[1, -17],[1, b]]) + 1 * det([[1, b],[1, -17]]).

Compute each:

det([[b, -17],[-17, b]]) = b*b - (-17)(-17) = b^2 - 289.

det([[1, -17],[1, b]]) = 1*b - (-17)*1 = b + 17.

det([[1, b],[1, -17]]) = 1*(-17) - b*1 = -17 - b = -(b+17).

So determinant = a*(b^2-289) -1*(b+17) +1*(-(b+17)) = a(b^2-289) - (b+17) - (b+17) = a(b^2-289) - 2(b+17).

Thus det = (3-λ)[(19-λ)^2 - 289] - 2[(19-λ)+17].

Simplify (19-λ)^2 - 289 = (19-λ)^2 - 17^2 = (19-λ -17)(19-λ+17) = (2-λ)(36-λ). Because 19-λ-17 = 2-λ, and 19-λ+17 = 36-λ. So factor: ((19-λ)^2 - 289) = (2-λ)(36-λ).

Also (19-λ)+17 = 36-λ.

Thus det = (3-λ)*(2-λ)*(36-λ) - 2*(36-λ) = (36-λ)[(3-λ)(2-λ) - 2].

So det = (36-λ)[(3-λ)(2-λ) - 2].

Compute (3-λ)(2-λ) = (3*2) -3λ -2λ + λ^2 = 6 -5λ + λ^2. Then subtract 2: (6 -5λ + λ^2) - 2 = λ^2 -5λ +4 = (λ-1)(λ-4). Because (λ-1)(λ-4)=λ^2-5λ+4.

Thus det = (36-λ)*(λ-1)*(λ-4).

Set =0 gives eigenvalues: λ = 36, λ = 1, λ = 4.

So eigenvalues are 36, 4, 1. Great! They are perfect squares.

Thus singular values are sqrt(36)=6, sqrt(4)=2, sqrt(1)=1. In decreasing order: 6, 2, 1.

So answer: 6, 2, 1.

But we need to list them as a comma-separated list of integers: 6,2,1. Usually they want decreasing order, each repeated according to multiplicity. Since all have multiplicity 1, we list each once.

Thus final answer: ANSWER: 6,2,1

We should ensure that singular values are the square roots of eigenvalues of A^T A, which are nonnegative. Indeed all are positive.

Thus done.
