We are given an ideal gas with γ = 7/5. The gas undergoes a closed cycle of 11 quasi-static processes. We need to find the net work done by the gas over one full cycle. The work is positive if the gas does net positive work. We need to compute the work for each process and sum them. Since it's a cycle, the net work is also the area enclosed in the p-V diagram. But we can compute each process work.

We are given p1 = 118 kPa, V1 = 3 L. The processes are:

1→2: isothermal, until V2 = 2 L
2→3: reversible adiabatic, until V3 = 3 L
3→4: isobaric, until V4 = 2 L
4→5: isochoric, until p5 = 59 kPa
5→6: isobaric, until V6 = 4 L
6→7: isochoric, until p7 = 97 kPa
7→8: isothermal, until V8 = 7 L
8→9: isobaric, until V9 = 14 L
9→10: isochoric, until p10 = 73 kPa
10→11: isobaric, until V11 = 3 L
11→1: isochoric, until p1 = 118 kPa (back to state 1)

We need to compute work done in each process. For isochoric (constant volume) processes, work = 0. For isobaric (constant pressure), work = p ΔV. For isothermal, work = nRT ln(Vf/Vi) = p_i V_i ln(Vf/Vi) (since pV = nRT). For adiabatic reversible, work = (p_f V_f - p_i V_i)/(1-γ) = (p_i V_i - p_f V_f)/(γ-1) because for reversible adiabatic, pV^γ = constant, and work = ∫ p dV = (p_i V_i - p_f V_f)/(γ-1). Also we can compute using temperatures.

We must be careful with units: pressure in kPa, volume in L. Since 1 kPa·L = 1 J, we can compute work in J directly.
