We are given a 6x6 integer matrix A. We need to compute its adjugate (classical adjoint), which is the transpose of the cofactor matrix. That means for each entry (i,j), the adjugate matrix adj(A) has entry (j,i) equal to the cofactor C_{ij} = (-1)^{i+j} det(M_{ij}), where M_{ij} is the submatrix obtained by deleting row i and column j. Then A * adj(A) = det(A) I.

We need to compute all 36 entries of adj(A) row by row, i.e., we list adj(A)_{1,1}, adj(A)_{1,2}, ..., adj(A)_{1,6}, then adj(A)_{2,1}, ..., adj(A)_{2,6}, and so on up to row 6. Output as a comma-separated list of integers.

Since A is 6x6, computing the adjugate directly via cofactor expansions for each entry would be heavy (36 determinants of 5x5 matrices). However, we can use the relation A * adj(A) = det(A) I, so if we can compute det(A) and also compute the inverse of A (if A is invertible), then adj(A) = det(A) * A^{-1}. But A might be singular? We need to compute adj(A) regardless. However, if det(A) is nonzero, we can compute the inverse (e.g., by Gaussian elimination) and multiply by det(A) to get adj(A). If det(A)=0, then adj(A) might still be nonzero, but then we need to compute it directly or via other means. So first, compute det(A) to see if it's zero.
