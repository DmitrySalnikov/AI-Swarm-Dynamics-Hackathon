Since the track is straight segments, the speed at end of each segment can be computed using work-energy theorem: change in kinetic energy = work done by gravity + work done by friction (and any other forces, but normal force does no work). No air resistance. The block stays in contact, no loss at junctions, so we can simply compute successive speeds.

For each segment i, we have:

- length L_i (m)
- angle relative to horizontal: For downhill: positive angle (inclined downwards); for uphill: negative angle? Typically, we consider angle θ measured from horizontal. For downhill, the block moves downward, so gravity does positive work (component along motion: mg sinθ, where θ is the angle of incline below horizontal). For uphill, gravity does negative work: -mg sinθ, where θ is angle above horizontal. But careful: The problem states "downhill incline at X° to the horizontal" meaning the surface slopes downward, so the block moves down; "uphill incline at X° to the horizontal" means it slopes upward, so block moves up. So we can define θ as the magnitude of the angle, and sign based on direction: downhill: +mg sinθ * L (positive work); uphill: -mg sinθ * L (negative work). For horizontal, θ=0, no gravity work.

Friction work: always opposes motion, so negative: -μ_k * N * L, where N is normal force. On incline, N = mg cosθ (since no other vertical forces). On horizontal, N = mg. So friction work = -μ_k * m g cosθ * L (for incline) or -μ_k * m g * L (horizontal). Note: For uphill, cosθ is same positive.

Thus, total work done on block over segment = W_gravity + W_friction.

Work-energy: (1/2) m v_f^2 - (1/2) m v_i^2 = W_total.

Cancel m: v_f^2 = v_i^2 + 2*(W_total/m). So v_f^2 = v_i^2 + 2*( (g sinθ * L if downhill, -g sinθ * L if uphill, 0 if horizontal) - μ_k g cosθ * L ) except for horizontal, where sinθ=0, cosθ=1.

Thus, we can compute v_f from v_i by:

v_f^2 = v_i^2 + 2 * g * L * ( sinθ - μ_k cosθ ) for downhill (θ positive)
v_f^2 = v_i^2 + 2 * g * L * ( - sinθ - μ_k cosθ ) for uphill (since gravity opposes motion)
For horizontal: v_f^2 = v_i^2 + 2 * g * L * ( - μ_k ) because sinθ=0, cosθ=1 => - μ_k

But careful: For horizontal, friction work = -μ_k mg L, so contribution = -2 μ_k g L.

Thus, we can compute sequentially. Since the block never stops, v_i always positive, but v_f may be larger or smaller.
