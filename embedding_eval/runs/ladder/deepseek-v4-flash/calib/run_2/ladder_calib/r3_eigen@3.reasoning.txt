Row1: -10, 0, 6
Row2: 2, -5, -1

Compute characteristic polynomial: det( A - λI ) = 
| -10-λ   0       6     |

det = (-5-λ) * det( [ -10-λ, 6; -12, 8-λ ] ).

Compute the 2x2 determinant: (-10-λ)(8-λ) - (6)(-12) = (-10-λ)(8-λ) + 72.

Expand: (-10-λ)(8-λ) = -10*8 +10λ -λ*8 + λ^2? Wait: (a+? Actually careful: (-10-λ)(8-λ) = -(10+λ)(8-λ) but better multiply: (-10-λ)*(8-λ) = (-10)*(8) + (-10)*(-λ) + (-λ)*(8) + (-λ)*(-λ) = -80 +10λ -8λ + λ^2 = -80 +2λ + λ^2. So λ^2 + 2λ -80. Then plus 72 gives λ^2 + 2λ -8.

So the 2x2 det = λ^2 + 2λ - 8 = (λ+4)(λ-2)? Since (λ+4)(λ-2)=λ^2+2λ-8 yes.

Thus eigenvalues: λ = -5, -4, 2. All integers. They are distinct, so algebraic multiplicity 1 each.
