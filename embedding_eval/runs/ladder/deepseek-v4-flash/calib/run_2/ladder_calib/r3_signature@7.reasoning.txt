We are given a 7x7 symmetric integer matrix A. We need to find the signature (p, q) of the quadratic form Q(x) = x^T A x, where p is the number of positive eigenvalues (or positive squares in a diagonalization) and q the number of negative eigenvalues. Since it's real symmetric, the signature is determined by the signs of the eigenvalues.

We could compute the eigenvalues, but that would be messy. Instead, we can perform Gaussian elimination (completing squares) to transform into a sum of squares with coefficients. Since matrix is given integer, we can do row/column operations preserving congruence (i.e., performing symmetric operations). Equivalently, we can compute the determinants of leading principal minors (if they are all non-zero) to determine the index via Sylvester's law of inertia for real symmetric matrices: the number of positive eigenvalues equals the number of sign changes in the sequence of leading principal minors, but only if all leading principal minors are non-zero. However, they may be zero; we need to handle that. Alternatively, we can perform diagonalization by completing squares.

Given the size 7, we can attempt to compute the characteristic polynomial? That would be heavy. Better to perform symmetric Gaussian elimination, i.e., use elementary operations that preserve congruence: for each pivot, we can subtract multiples of that row/column from others. Since the matrix is integer, we might get fractions but we can keep exact rational numbers.

We can also compute the inertia by using the LDL^T decomposition or performing Cholesky-like factorization with pivoting. Since the matrix may be indefinite, we might need to handle zeros.
