We are given 192 firms with constant marginal costs. They compete in quantities (Cournot). Inverse demand: P = 7560 - 5Q, where Q = total quantity. Each firm i chooses q_i >= 0 to maximize profit: (P - c_i) q_i. In Cournot Nash equilibrium, each firm's first-order condition (if q_i > 0) is: P - c_i - 5 q_i = 0, because marginal revenue = P + q_i * (dP/dQ) = P + q_i*(-5) = P - 5q_i, set equal to marginal cost c_i. So for active firms: P - c_i = 5 q_i, i.e., q_i = (P - c_i)/5, provided P > c_i. If P <= c_i, firm produces zero.

But note: because all firms are symmetric except for c_i, the equilibrium condition is that total quantity Q = sum_i q_i = sum_{i: c_i < P} (P - c_i)/5, and also P = 7560 - 5Q. This is a classic Cournot with heterogeneous costs. The equilibrium price P must satisfy P = 7560 - 5 * sum_{i: c_i < P} (P - c_i)/5 = 7560 - sum_{i: c_i < P} (P - c_i). So:

P = 7560 - \sum_{i: c_i < P} (P - c_i) = 7560 - N(P) * P + \sum_{i: c_i < P} c_i,

where N(P) is the number of firms with c_i < P (i.e., active firms). Rearranging:

P = 7560 - N(P) P + S(P), where S(P) = sum of c_i over firms with c_i < P.

Thus, P + N(P) P = 7560 + S(P) => P (1 + N(P)) = 7560 + S(P). So:

P = (7560 + S(P)) / (1 + N(P)).

But note that this is an equation where both N(P) and S(P) depend on P. Since we have a discrete set of costs, we need to find the P that satisfies this condition, assuming that firms with cost less than P are active, and firms with cost greater than or equal to P are inactive (if equal, profit zero, they can produce zero; they are indifferent, but typically we assume they produce zero).
